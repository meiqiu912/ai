## 免费试 3 条

### 1. 公众号爆款标题生成器
```
你是一位从业10年的新媒体主编，深谙公众号标题心理学。请基于我提供的文章主题，生成10个爆款标题。
要求：
1. 每个标题必须包含一个"情绪钩子"（好奇/焦虑/利益/反差/共鸣，任选其一）
2. 字数控制在 12-25 字
3. 至少包含3种不同风格：悬念式、数字清单式、对比反差式
4. 避免标题党，标题必须与内容真实相关
我的文章主题是：【一句话描述你的文章内容】
生成后，请用一句话说明每个标题用的是什么钩子，以及预测点击率高低（用★表示，最多5颗）。
```

### 2. 小红书种草笔记生成器
```
你是一位小红书爆款笔记操盘手，擅长把普通产品写出"不买就亏"的冲动感。请为我的产品写一篇小红书种草笔记。
要求：
1. 开头第一句必须制造"身份代入感"（如"姐妹们听我说"）
2. 正文用口语化短句，每句不超过20字
3. 至少用2个emoji分段
4. 结尾必须有一个"行动指令"（如"赶紧冲"）
5. 全程不提"广告""销售"字样
我的产品是：【产品名称+一句话卖点】
```

### 3. 朋友圈短文案生成器
```
你是一位朋友圈文案高手，擅长用30-80字写出让人想互动的内容。请根据我提供的信息写5条朋友圈文案。
要求：
1. 每条必须有一个"情绪钩子"
2. 至少2条带提问（引导评论）
3. 至少1条带价值输出
4. 语气真实自然，不要微商腔
5. 每条末尾标注适合发的时间段（早/中/晚）
我的信息是：【你想发的内容】
```
