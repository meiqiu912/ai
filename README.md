## 免费干货：8步工作流精要

1. **选题聚焦**：不研究"大而空"，用提示词收敛成可执行的科学问题
2. **文献地图**：10分钟摸清一个领域的脉络（流派/关键作者/争议点）
3. **综述骨架**：先搭结构再填肉，避免文献堆砌
4. **大纲设计**：从3级标题开始，论文就赢了一半
5. **分节初稿**：逐节喂提示词，AI只写一节，你掌控全局
6. **学术润色**：把"AI味"改成"期刊味"（最关键一步）
7. **降重自查**：合规降重 vs 学术不端的红线，必须分清
8. **投稿审稿**：选刊策略 + Cover Letter + 回复审稿人
